## birthday-card-13-employee-warm-image 项目分析

> 分析日期：2026-06-23
> 模板类型：工会生日电子贺卡（暖色调员工关怀版）

---

### 一、项目概述

这是一个 4 屏全屏翻页式生日贺卡模板，采用深梅紫底色 + 金色点缀的暖色调设计，毛玻璃面板居中展示文字内容。支持自动播放（点击"开启祝福"后逐屏推进）和手动翻页两种模式。

最终交付物为 `template-standalone.html`——一个完全自包含的单文件 HTML（约 1.4 MB），所有图片、CSS、JS、音乐均以 base64 内嵌，可直接部署到任何静态服务器或通过短信链接发送。

### 三、HTML 结构（index.html）

#### 全局元素

| 元素 | 作用 |
|------|------|
| `#fxCanvas` | 全屏 Canvas，绘制粒子特效（浮尘/彩纸/烟花） |
| `#autoProgress` | 底部 3px 金色进度条，自动播放时显示 |
| `.music-toggle` | 右上角音乐开关按钮（CSS 绘制音符图标，无图片） |
| `.page-dots` | 底部 4 个导航圆点 |

#### 四屏结构

每屏都是一个 `<section class="screen" data-screen="xxx">`，同一时间只有一屏拥有 `.active` 类名。

**第 1 屏 — 封面（cover）**

- 背景：01-cover-bg.png（eager 加载）
- 品牌区：左上角 logo + 公司名（logo 加载失败时 fallback 为文字）
- 文案面板：eyebrow 小标签 → 大标题"生日快乐" → 英文副标题 → 引导语 → "开启祝福"按钮
- "开启祝福"按钮带有 `data-auto="true"`，点击后触发自动播放
- 底部有滚动引导箭头（CSS 动画上下弹跳）

**第 2 屏 — 祝福（wish）**

- 品牌区同上
- 文案面板：eyebrow "For {{name}}" → 员工姓名 → 祝福语（`{{blessing}}`，用 `<!-- editable-start/end -->` 标记）→ 签名语 → "继续翻页"按钮

**第 3 屏 — 高光（highlight）**

- 文案面板：eyebrow → 标题 → 正文段落 → "来自{{company}}的一份生日心意" → "走向高光"按钮（ghost 幽灵按钮样式）

**第 4 屏 — 结尾（final）**

- 面板更宽（600px vs 560px）
- 文案面板：eyebrow → 标题 → 正文 → 正式落款区（`{{sender}} 敬贺` + 日期）→ "再看一次"按钮（跳回封面）
- 此屏触发烟花特效

#### 占位符清单

| 占位符 | 含义 | 出现次数 |
|--------|------|----------|
| `{{title}}` | 页面标题 | 1 |
| `{{logo_url}}` | 企业 logo 图片 URL | 4（每屏一次） |
| `{{company}}` | 企业名称 | 6 |
| `{{name}}` | 员工姓名 | 3 |
| `{{blessing}}` | 个性化祝福语 | 1 |
| `{{sender}}` | 发送方（落款） | 1 |
| `{{year}}` `{{month}}` `{{day}}` | 日期 | 各 1 |
| `{{music_url}}` | 背景音乐 URL（在 script.js 中） | 1 |

### 四、CSS 架构（style.css，677 行）

#### 设计令牌

```
--ink: #fff8f0           主文字色（暖白）
--soft-ink: 84% 透明度    次要文字
--muted-ink: 64% 透明度   辅助文字
--gold: #efc37d           金色强调
--amber: #d7a65b          琥珀色
--peach: #ffd8bb          桃色
--berry: #8c5860          莓果色
--line / --panel / --shadow   半透明边框、面板、阴影
```

#### 核心布局

- **屏幕切换**：`.screen` 使用 `opacity + transform(translateY + scale) + visibility` 过渡，时长 0.88s。非活跃屏幕不可见且下移 18px、缩小到 98.8%。
- **背景呼吸**：`.scene-bg` 以 10s 周期在 `scale(1.08)` 和 `scale(1.03)` 之间缓慢交替，营造微妙的 Ken Burns 效果。
- **场景遮罩**：每屏有独立的双层渐变遮罩（`.scene-overlay-xxx`），提升文字可读性。
- **文案面板**：绝对居中（`left:50%; top:50%; transform:translate(-50%,-50%)`），毛玻璃效果（`backdrop-filter: blur(18px)` + 半透明渐变背景 + 边框 + 阴影），最大宽度 560px（结尾页 600px），可滚动（隐藏滚动条）。

#### 动画系统

**关键帧定义**：

| 名称 | 效果 | 用途 |
|------|------|------|
| `fadeIn` | 透明度 0→1 | 面板入场 |
| `floatUp` | 下移 26px→归位（保持居中） | 面板入场 |
| `finalRise` | 同 floatUp | 结尾面板（语义区分） |
| `childFadeUp` | 透明度 0 + 下移 20px→归位 | 逐元素入场 |
| `bgDrift` | scale 1.08→1.03 | 背景呼吸 |
| `scrollBounce` | 上下弹跳 8px | 滚动引导箭头 |

**面板入场**：`.screen.active .copy-panel` 触发 `fadeIn + floatUp`（0.92s），每次切屏重新播放。

**逐元素入场（stagger）**：JS 给 `.copy-panel` 添加 `.stagger-animate` 类后，其直接子元素（eyebrow、h1/h2、english-title、hero-copy、message、signature-copy、support-note、正文 p、按钮）按 0.22s 间隔依次执行 `childFadeUp`（0.6s）。

#### 响应式断点

| 断点 | 调整内容 |
|------|----------|
| ≤480px | 面板全宽减 24px，字号/按钮/品牌区缩小 |
| ≤360px | 进一步缩减 padding 和字号 |
| ≤700px 高 | 面板 max-height 减小 |

#### 无障碍

`@media (prefers-reduced-motion: reduce)` 禁用所有动画和过渡，JS 侧也会跳过自动播放并减少粒子数量。

### 五、JS 逻辑（script.js，536 行）

#### 配置与状态

```
screenOrder = ["cover", "wish", "highlight", "final"]
palettes = { cover: [...], wish: [...], highlight: [...], final: [...] }  // 每屏粒子配色
staggerDelay = 0.22  // 逐元素入场间隔（秒）
autoPlayInterval = 5000  // 手动模式回退间隔（ms）
reduceMotion = matchMedia("(prefers-reduced-motion: reduce)").matches
```

#### 屏幕切换

`showScreen(name)` 是核心函数：切换 `.active` 类 → 更新导航点 → 重置彩纸 → 触发 stagger 动画 → 淡出滚动箭头 → 尝试播放音乐 → 启动/停止烟花。

#### 逐元素动画（animateStaggerChildren）

1. 找到目标屏的 `.copy-panel`
2. 清除旧动画状态（移除 `.stagger-animate` 和 `.stagger-child`）
3. 收集匹配选择器的直接子元素
4. 为每个子元素设置 `animation-delay = i × 0.22s`
5. 强制回流后添加 `.stagger-animate` 触发动画
6. 返回总动画时长 = `(元素数 - 1) × 0.22 + 0.6` 秒

#### 自动播放

`getAutoPlayDuration()` 根据当前屏子元素数量动态计算停留时间：

```
停留时间 = 逐元素动画总时长 + 2.2 秒阅读停留
```

`startAutoPlay()` 使用递归 `setTimeout`（非 setInterval），每次切屏后重新计算下一屏的时长。进度条速度跟随实际时长。任何手动操作（滑动/滚轮/键盘/点击导航点）都会停止自动播放。

以祝福页为例：5 个子元素 → `(5-1) × 0.22 + 0.6 + 2.2 = 3.68 秒`。

#### Canvas 粒子系统

| 粒子类型 | 数量 | 活跃屏幕 | 效果 |
|----------|------|----------|------|
| 浮尘（dust） | 40（减动模式 14） | 所有屏幕 | 小光点缓慢飘落，正弦水平摆动 |
| 彩纸（confetti） | 12（减动模式 4） | highlight + final | 旋转矩形碎片下落 |
| 烟花（fireworks） | 每簇 24 火花 | final | 十字形火花放射 + 重力 + 衰减 |

渲染循环使用 `requestAnimationFrame`，页面不可见时暂停以节省性能。Canvas 支持 DPR 适配（上限 2x）。

#### 音乐控制

优先使用 `{{music_url}}`（模板模式下由服务端替换为 base64 data URI），否则 fallback 到 `assets/music.mp3`。创建循环播放的 Audio 对象，支持微信浏览器桥接（`WeixinJSBridgeReady` 事件）。离开封面时自动尝试播放（受浏览器自动播放策略限制）。

#### 导航方式

| 方式 | 行为 |
|------|------|
| `[data-next]` 按钮 | `data-auto="true"` → 启动自动播放；否则停止自动播放 + 跳转 |
| 导航圆点 | 停止自动播放 + 直接跳转 |
| 触摸滑动 | 阈值 72px，停止自动播放 + 翻页 |
| 鼠标滚轮 | 阻止默认行为，850ms 防抖，停止自动播放 + 翻页 |
| 键盘方向键/空格 | 停止自动播放 + 翻页 |

#### 文本格式化

`formatBlessingText()` 将含中文逗号 `，` 或分号 `；` 的文本拆分为多个 `<span class="comma-line">` 块级元素，每段独占一行，并移除末尾句号 `。`。在 DOMContentLoaded 和脚本加载时各执行一次（双重保障）。

### 六、template-standalone.html（最终交付物）

这是一个约 1.4 MB 的自包含单文件 HTML，包含：

- 所有 CSS 内联在 `<style>` 标签中
- 所有 JS 内联在 `<script>` 标签中
- 4 张背景图以 `data:image/jpeg;base64,...` 格式内嵌（PNG 压缩为 JPEG 80% 质量，总计约 792 KB base64）
- 背景音乐以 `data:audio/mpeg;base64,...` 格式内嵌（压缩为 64kbps mono 22050Hz，约 343 KB base64）
- 保留所有 `{{placeholder}}` 占位符，服务端替换后即可使用

此文件不依赖任何外部资源，可直接通过 HTTP 链接打开，适合短信/彩信发送场景。

### 八、开发工作流

1. **本地调试**：直接用浏览器打开 `index.html`（引用外部 CSS/JS/assets）
2. **修改样式/逻辑**：编辑 `style.css` 和 `script.js`，刷新 `index.html` 预览
3. **打包交付**：通过构建脚本将 CSS/JS 内联 + 图片转 JPEG + 音乐压缩为 base64，生成 `template-standalone.html`
4. **服务端集成**：后端读取 `template-standalone.html`，替换 `{{placeholder}}` 后返回给客户端
